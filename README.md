# SoundShot

**Звук + запись экрана для Windows в одной лёгкой программе.** Работает с любыми наушниками,
гарнитурами и колонками: эквалайзер, эффекты, микрофон с шумоподавлением, громкость каждой программы,
мини-плеер, запись экрана и мгновенный повтор, скриншоты, профили для игр — и панель поверх игр
по Win + G / Ctrl + Alt + G.

### Лучше всего — с наушниками io Graphite

С **io Graphite 2 Pro (MAX) Wireless** и другими гарнитурами на чипе C-Media SoundShot управляет
драйвером напрямую: родной 10-полосный эквалайзер, Surround 7.1, Audio Brilliant, Dynamic Bass,
Smart Volume, Voice Clarity, AI-шумоподавление и Magic Voice для микрофона — всё, что умеет штатный
Audio Center, только удобнее и быстрее, без него самого. С любыми другими устройствами эквалайзер
работает через бесплатный Equalizer APO.

### Почти не нагружает компьютер

Замер в трее с включённым 5-минутным повтором записи экрана: **≈ 50 МБ оперативной памяти и
0,1–0,2 % процессора**. Скачивается одним файлом — ничего устанавливать не нужно,
работает без прав администратора.

## Мини-плеер (версия 2.1)

- В панели быстрых настроек — что сейчас играет: обложка, название, исполнитель, программа.
- Полоса времени: сколько прошло и сколько осталось, перемотка мышью.
- Предыдущий / пауза / следующий трек.
- Подхватывает музыку откуда угодно, что показывает Windows в своём регуляторе громкости:
  Apple Music, Яндекс Музыка, Spotify, VK Музыка, YouTube и другие сайты в Яндекс Браузере,
  Chrome, Edge, Firefox, плееры. Если играет несколько — берётся то, что звучит сейчас.
- Горячие клавиши (меняются в «Горячие клавиши» → «Музыка»): Ctrl + Alt + Пробел — пауза,
  Ctrl + Alt + → — следующий, Ctrl + Alt + ← — предыдущий. При переключении трека — подсказка на экране.

## Запуск

Ярлык программы на рабочем столе и в «Пуске» → `App\GraphiteCompanion.exe`.

- `--tray` — запуск свёрнутым в трей (так работает автозапуск);
- `--flyout` — открыть мини-панель у уже запущенного приложения (можно повесить на кнопку мыши).

Пересобрать: `dotnet publish -c Release -o App` в этой папке (нужен .NET 10 SDK).

## Возможности

- Встроенный 10-полосный эквалайзер драйвера C-Media (30 Гц – 16 кГц, ±20 дБ) — без
  дополнительных драйверов и без прав администратора.
- 9 пресетов: амбушюры (ткань / кожзам / велюр) × режим (игры / музыка / фильмы).
  Любой пресет можно подправить; «Сбросить пресет» возвращает заводские значения.
- Свои пресеты с названиями. При первом запуске текущие настройки Audio Center
  сохраняются как пресет «Из Audio Center».
- Все эффекты из Audio Center (вкладка «Эффекты»): объёмный звук 7.1 (режим, размер комнаты),
  Audio Brilliant, Dynamic Bass (уровень, частота среза), Smart Volume (уровень, режим),
  Voice Clarity (уровень, подавление шума) + кнопка «Стандартные настройки».
- Микрофон (вкладка «Микрофон»): громкость, отключение, AI-шумоподавление, Magic Voice.
- Громкость и отключение звука.
- Работа из трея, автозапуск, глобальные горячие клавиши (подбираются свободные:
  Ctrl+Alt+1/2/3 или Ctrl+Alt+F1/F2/F3 и т.д. — фактические показаны на карточках режимов).
- Автоматически находит наушники и применяет настройки при переподключении.

## Как это устроено

Эквалайзер пишется в пользовательское хранилище эффектов Windows 11
(`IAudioSystemEffectsPropertyStore`, контекст `{4c6c316b-c24f-421c-a266-690540cabd11}`) —
туда же пишет официальный Audio Center, и драйвер сразу применяет изменения.
Ключ `{bd341ffb-9fd1-4ed4-8159-7999d546ea8a}`: `,0` — EQ вкл/выкл, `,1`…`,10` — полосы в дБ.

Ключи эффектов (fmtid → pid):
- `{c020cdbf-756f-4b6d-9031-be6e20cf1c9f}` Surround 7.1: 0 вкл, 5 режим (1 музыка/игры, 0 фильмы), 2 комната (2 S, 1 M, 0 L)
- `{5e96e4d9-ff2c-4d84-9bd6-fe10cf815009}` Xear: 0/1 Audio Brilliant вкл/уровень; 5/7/8 Dynamic Bass вкл/уровень/срез;
  9/10/11 Smart Volume вкл/уровень/режим; 2/3/4 Voice Clarity вкл/уровень/подавление
- Микрофон: `{d9d2c54d-289d-4bf2-8bef-3270c977ae33}`,1 — AI шумоподавление;
  `{3bc6329a-2397-4ff3-92f5-2cd9894bb889}`,2 — Magic Voice вкл, ,3 — голос (0 монстр, 1 мульт, 2 муж., 3 жен.)

Значения, которых нет в пользовательском хранилище, читаются из `FxProperties` в реестре
(Audio Center держит часть настроек там).

Официальная папка `D:\io Graphite 2 Pro Wireless Audio Center` и драйвер не изменяются.
Не рекомендуется одновременно менять эквалайзер в Audio Center и здесь.

Настройки: `%APPDATA%\GraphiteCompanion\settings.json`, ошибки — `error.log` там же.
